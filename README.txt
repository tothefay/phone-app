แพ็กเกจแอป Phone (PWA)
ไฟล์: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png

วิธีใช้เป็นแอป (ไม่ต้องมีคอม)
1) อัปโหลดไฟล์ทั้ง 5 ไฟล์ไปไว้ที่เดียวกันบนเว็บโฮสต์ฟรี เช่น GitHub Pages, Cloudflare Pages หรือ Netlify
2) เปิดลิงก์นั้นใน Chrome แล้วกด ⋮ > ติดตั้งแอป (หรือ เพิ่มลงหน้าจอหลัก) จะได้ไอคอนและเปิดเต็มจอ ใช้ออฟไลน์ได้
3) อยากได้ไฟล์ .apk: เข้า pwabuilder.com ใส่ลิงก์เว็บของคุณ แล้วเลือก Package for Android เพื่อดาวน์โหลดไฟล์ติดตั้ง

ย้ายข้อมูลจากหน้าเว็บเดิม: ในหน้าเดิมกด ตั้งค่า > ส่งออกข้อมูล คัดลอกข้อความ แล้วไปที่แอปใหม่ กด ตั้งค่า > นำเข้าข้อมูล
